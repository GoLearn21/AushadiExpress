# Nestam — Unity 6 project

Open `Nestam/` in Unity Hub (6000.0 LTS), then use the **Nestam** menu:

1. **Build Main Scene** — generates the scene, resources and UI settings.
2. **Install Telugu Font** — downloads Noto Sans Telugu and creates the font asset.
3. **Build Android APK / iOS Xcode Project**.

Setup, troubleshooting and the character rig are documented in [../docs/05-UNITY_SETUP.md](../docs/05-UNITY_SETUP.md).
